## Short Description (160 characters max)

```
Python web scraper for BetterDocs documentation sites. Auto-discovers content and exports to JSON, Markdown & CSV. Easy to configure.
```

## About Section
```
A powerful and user-friendly Python web scraper designed to extract all content from BetterDocs-powered documentation websites. Features automatic category and article discovery, progress tracking, robust error handling, and exports data in multiple formats (JSON, Markdown, CSV). Built with BeautifulSoup and includes rate limiting to be respectful to servers. Perfect for backing up documentation, creating offline copies, or migrating content.
```
